# Stalytex AI Analytics Frontend

This folder now contains a modern React/Vite analytics dashboard for Stalytex.

## Setup

1. Open a terminal in `phase 2/stalytex_backend_full/frontend`
2. Run `npm install`
3. Run `npm run dev`

## Features

- Drag-and-drop CSV/XLSX upload
- AI-style dataset insights and chat
- Interactive responsive charts
- Advanced table viewer with sorting, filtering, and pagination
- Data cleaning and export-ready workspace

## Notes

- The interface is built with React, Vite, Recharts, and React Grid Layout.
- Legacy HTML files are no longer used by the dashboard.
